tacet — a coerced order that looks exactly like a genuine one

Two operators must authorise an irreversible order (a wire transfer, a command release) over a link an adversary can watch — while one of them may be forced. TACET makes the coerced order silently harmless: nothing visible on the device, on the wire or on the screen reveals it, yet the control centre reacts correctly.

1 · What an eavesdropper sees

A normal link transmits only when something happens, so timing alone gives the order away. TACET sends one fixed 64-byte encrypted frame in every time slot, real or cover. Send some orders and compare.

What the observer records (time → frame)

Observer accuracy at telling “order” from “cover”
51.0 % — chance level (experiment E1)

Each slot carries exactly 64 bytes, sent on a fixed clock. Real and cover frames are both encrypted; they differ in nothing the observer can measure. Cost: an order waits for the next slot.

2 · One order, three points of view

Enter PINs like the two operators would. The terminal never verifies a PIN — it always answers “ORDER SENT”. Only the control centre (C2) knows which PIN is normal and which is the duress PIN. Demo PINs are public: operator 1 = 482915 (duress 482951), operator 2 = 739206 (duress 739260).

Honest limits

Modelled, not simulated

The radio is a model (tchannel.py); Wokwi has no LoRa part. The C2 runs on the same MCU in the demo. Operators in scenarios are scripted.

Weak signals

Typing-rhythm results are synthetic: at z = 3, false-positive rate 2.0 %, detection 52 % — a risk escalator (HOLD), never a lock. If the terminal key and one captured frame are stolen, a 6-digit PIN falls offline in about two seconds (E5). Demo keys are public.
